# Diabetes Prediction & Analysis App

A machine learning application for predicting diabetes risk and analyzing diabetes-related patterns in datasets.

## Overview

This application uses machine learning models to predict diabetes risk based on medical and demographic factors. It provides comprehensive analysis tools for understanding diabetes patterns and risk factors.

## Features

- **Diabetes Risk Prediction**: Predict diabetes likelihood based on input features
- **Data Analysis**: Explore and visualize diabetes-related patterns in datasets
- **Model Evaluation**: Assess model performance with multiple metrics
- **Interactive Interface**: User-friendly UI for easy interaction
- **Feature Importance**: Understand which factors influence predictions

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Lakshmi1369/diabetes--prediction--Analysis-App.git
cd diabetes--prediction--Analysis-App
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. (Optional) Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

## Usage

Run the application:
```bash
python app.py
```

Then navigate to the provided URL in your browser to access the interface.
